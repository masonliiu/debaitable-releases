# DebAItable — releases

DebAItable puts Claude, ChatGPT and local models at one table: they debate your question and hand you a verdict.

This repository only hosts the downloadable builds. Get the app and docs at **https://debaitable.com**.

- Linux: download the AppImage or .deb from [Releases](https://github.com/masonliiu/debaitable-releases/releases).
- CLI: `npx debaitable room`
